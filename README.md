# 🧘 Noniko Daily Meditation Companion

A simple WordPress plugin for displaying a **daily meditation** directly on your website.

## ✨ Features

- 🧘 Daily meditation
- 📅 Meditation by date
- 🇵🇱 Polish & 🇬🇧 English
- 🗄️ Local database
- 🧩 Simple shortcode
- 🔒 No external API required

## 🚀 Usage

Add the shortcode to any WordPress page or post:

```text
[noniko_daily_meditation]
```

Display a specific date:

```text
[noniko_daily_meditation date="01-03"]
```
## 📦 Requirements
-WordPress 6.9+
-PHP 7.4+
